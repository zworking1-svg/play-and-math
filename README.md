# 🦉 Считай с Филей

Игра на умножение для детей 7–12 лет. Совёнок Филя даёт примеры, ребёнок решает их, набирает
рейтинг, открывает награды, наряжает Филю и соревнуется с другими игроками в общем рейтинге.

Игра состоит из обычных файлов (`index.html`, `style.css`, `game.js`, `config.js`): сервер и сборка
ей не нужны. Каждый открывает ссылку на своём смартфоне и играет. Общий онлайн-рейтинг хранится
в бесплатной базе Firebase.

## Правила и механики

| Механика | Как работает |
|---|---|
| ✖️ Только умножение | От `3 × 4` до `67 × 48` и `7 × 4 × 12` — сложность зависит от возраста и уровня |
| ❤️ Сердечки | В начале 10. Ошибка или конец времени забирают одно. Кончились — игра заново, рейтинг обнуляется |
| ⏰ Время на пример | От 15 секунд (таблица умножения) до 75 секунд (двузначное на двузначное) |
| ⭐ Рейтинг | За верный ответ: `10 × сложность`. Чем выше уровень — тем больше очков |
| 🔥 Комбо | 5 верных подряд — очки ×2, 10 подряд — ×3 |
| 💖 Новое сердечко | Каждые 10 верных ответов подряд (максимум 10) |
| ⚡ Бонус за скорость | Ответ быстрее 7 секунд — дополнительные очки |
| 📈 Уровни | Каждые 5 верных ответов — новый уровень, каждые 2 уровня примеры сложнее |
| 👑 Супер-пример | Каждый 10-й пример сложнее обычного, но даёт ×2 очков и 3 монеты |
| 💰 Монеты и подсказки | +1 монета за ответ. Подсказка (3 монеты) показывает 3 варианта, но очков вдвое меньше |
| 🦉 Наряды Фили | Уровень 2 — бабочка, 3 — очки, 5 — шапка учёного, 8 — корона |
| 🎖️ Награды | 12 достижений, остаются навсегда, даже после проигрыша |
| 🏆 Рекорды | Общий онлайн-рейтинг и «Мои игры», отдельно для каждой возрастной группы |

**Сложность по возрасту:**

- **7–8 лет** — таблица умножения на 2–5, потом вся таблица
- **9–10 лет** — вся таблица, потом двузначное на однозначное (`14 × 6`, `47 × 8`)
- **11–12 лет** — двузначное на однозначное, потом двузначное на двузначное (`11 × 23`) и три множителя

## 🔒 Честная игра (защита от подсказок)

Во время игры результат **сгорает**, а игра сразу заканчивается, если игрок:

- свернул браузер или переключился на другое приложение (калькулятор, ИИ-чат);
- переключился на другое окно или вкладку на компьютере;
- уменьшил окно браузера или открыл игру в режиме разделённого экрана;
- вышел из полноэкранного режима (на Android и компьютере игра открывается во весь экран).

Также во время игры нельзя выделить и скопировать пример, а на каждый пример даётся ограниченное
время. Поворот телефона нарушением не считается.

**Что веб-игра не может заметить:**

- второй телефон или калькулятор рядом (от этого частично спасает таймер);
- если взрослый подсказывает ответ;
- на iPhone полноэкранный режим недоступен, но сворачивание и переключение приложений
  отслеживаются так же.

Входящий звонок или всплывающее системное окно тоже могут остановить игру. Так работает строгая
защита: браузер не отличает звонок от переключения на калькулятор.

## Запуск на своём компьютере

Достаточно открыть `index.html` двойным щелчком. Или через локальный сервер:

```bash
python -m http.server 8765
```

и открыть http://localhost:8765

## Шаг 1. Публикация игры (бесплатно) — GitHub Pages

Адрес будет вида `https://ВАШ-ЛОГИН.github.io/play-and-math/`. Эту ссылку можно отправить детям:
она открывается на любом смартфоне.

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Создайте новый **публичный** репозиторий, например `play-and-math` (без README).
3. Отправьте туда проект:
   ```bash
   git remote add origin https://github.com/ВАШ-ЛОГИН/play-and-math.git
   git push -u origin master
   ```
4. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `master`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты игра будет доступна по ссылке, которую покажет эта страница.

Каждый следующий `git push` обновляет игру автоматически.

Альтернативы, тоже бесплатные: Netlify (https://app.netlify.com/drop — перетащить папку) и
Cloudflare Pages (https://pages.cloudflare.com).

## Шаг 2. Онлайн-рейтинг (бесплатно) — Firebase Firestore

Без этого шага игра работает, но рекорды видны только на устройстве самого игрока.
Бесплатный тариф Firebase (Spark) не требует банковской карты: 50 000 чтений и 20 000 записей
в день — с большим запасом для школы.

1. Откройте https://console.firebase.google.com и войдите через Google-аккаунт.
2. **Создать проект** → любое имя, например `play-and-math`. Google Analytics можно выключить.
3. В меню слева: **Build → Firestore Database → Create database** →
   регион `europe-west` (или ближайший) → **Start in production mode**.
4. Вкладка **Rules**: замените текст содержимым файла [firestore.rules](firestore.rules) → **Publish**.
5. Вкладка **Indexes → Composite → Create index**:
   коллекция `scores`, поля `age` — *Ascending*, `score` — *Descending* → **Create**.
   Индекс строится 1–5 минут.
6. Значок шестерёнки → **Project settings → General**:
   - скопируйте **Project ID**;
   - в разделе **Your apps** нажмите `</>` (Web), зарегистрируйте приложение и скопируйте `apiKey`.
7. Впишите оба значения в [config.js](config.js):
   ```js
   window.FIREBASE_CONFIG = {
     projectId: 'play-and-math-12345',
     apiKey: 'AIza...',
   };
   ```
8. Сделайте коммит и `git push` — рейтинг заработает у всех.

`apiKey` Firebase не секретный: он всегда виден в коде сайта. Защиту дают правила из
`firestore.rules`: читать рейтинг может любой, а добавлять — только правдоподобные результаты
(имя до 14 символов, не больше 3000 очков на уровень). Менять и удалять записи нельзя.
Удалить неприличное имя или подделанный результат можно вручную в консоли Firebase.
