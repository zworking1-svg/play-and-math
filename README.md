# 🦉 Считай с Филей

Математическая игра для детей 7–12 лет. Совёнок Филя даёт примеры, ребёнок решает их,
набирает рейтинг, открывает награды и наряжает Филю.

Игра — это три обычных файла (`index.html`, `style.css`, `game.js`). Ей не нужен сервер,
база данных или сборка, поэтому её можно бесплатно разместить где угодно.

## Правила и механики

| Механика | Как работает |
|---|---|
| ❤️ Сердечки | В начале 10. Ошибка забирает одно. Когда кончились — игра заново, рейтинг обнуляется |
| ⭐ Рейтинг | За верный ответ: `10 × сложность`. Чем выше уровень — тем больше очков |
| 🔥 Комбо | 5 верных подряд — очки ×2, 10 подряд — ×3 |
| 💖 Новое сердечко | Каждые 10 верных ответов подряд (максимум 10) |
| ⚡ Бонус за скорость | Ответ быстрее 7 секунд — дополнительные очки |
| 📈 Уровни | Каждые 5 верных ответов — новый уровень, каждые 2 уровня примеры сложнее |
| 👑 Супер-пример | Каждый 10-й пример сложнее обычного, но даёт ×2 очков и 3 монеты |
| 💰 Монеты и подсказки | +1 монета за ответ. Подсказка (3 монеты) показывает 3 варианта ответа, но очков за пример вдвое меньше |
| 🦉 Наряды Фили | Уровень 2 — бабочка, 3 — очки, 5 — шапка учёного, 8 — корона |
| 🎖️ Награды | 12 достижений, остаются навсегда, даже после проигрыша |
| 🏆 Рекорды | Топ-10 лучших игр на этом устройстве |

**Сложность по возрасту** (выбирается в меню):

- **7–8 лет** — сложение и вычитание до 20, потом до 100, потом таблица умножения
- **9–10 лет** — таблица умножения и деление, потом многозначные числа
- **11–12 лет** — двузначное на однозначное, потом двузначное на двузначное (`11 × 23`), скобки, порядок действий

Рекорды, награды, имя и настройка звука хранятся в браузере (`localStorage`) — на каждом
устройстве свои.

## Запуск на своём компьютере

Достаточно открыть `index.html` двойным щелчком. Или через локальный сервер:

```bash
python -m http.server 8765
```

и открыть http://localhost:8765

## Бесплатная публикация в интернете

### Вариант 1: GitHub Pages (рекомендую)

Бесплатно навсегда, адрес вида `https://ВАШ-ЛОГИН.github.io/play-and-math/`.

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Создайте новый **публичный** репозиторий, например `play-and-math` (без README).
3. Отправьте туда проект:
   ```bash
   git remote add origin https://github.com/ВАШ-ЛОГИН/play-and-math.git
   git push -u origin master
   ```
4. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `master`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты игра будет доступна по ссылке, которую покажет эта страница.

Каждый следующий `git push` автоматически обновляет игру.

### Вариант 2: Netlify Drop (без Git, за 1 минуту)

1. Откройте https://app.netlify.com/drop
2. Перетащите папку проекта в окно браузера.
3. Получите ссылку вида `https://случайное-имя.netlify.app` (имя можно поменять в настройках).

Бесплатный тариф Netlify требует регистрацию, чтобы ссылка не удалилась через час.

### Вариант 3: Cloudflare Pages

https://pages.cloudflare.com — бесплатно, подключается к репозиторию GitHub или принимает
загрузку папки. Адрес вида `https://play-and-math.pages.dev`.
